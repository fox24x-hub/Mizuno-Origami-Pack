# Mizuno Neo Vista 2 — Origami Pack

Персональный одностраничный сайт-подарок, который продолжает историю физической открытки после перехода по QR-коду. Драматургия страницы строится вокруг последовательности: **форма → структура → движение → подарок → будущий путь**.

Сайт написан на HTML, CSS и vanilla JavaScript. Он открывается без сборки, адаптирован прежде всего для смартфонов и готов к публикации на GitHub Pages.

## Структура

```text
/
├── index.html
├── styles.css
├── script.js
├── README.md

├── .github/workflows/pages.yml
└── assets/
    ├── images/

    │   ├── shoe-side.webp

    │   └── favicon.svg
    └── videos/
        ├── origami-film.mp4
        └── running-film.mp4
```

## Необходимые медиафайлы

Медиа не входят в репозиторий. Пока их нет, сайт показывает аккуратные градиенты и графические заглушки.

| Файл | Назначение | Рекомендация |
| --- | --- | --- |
| `assets/images/hero-shoe.webp` | Главное изображение кроссовка | Прозрачный фон, 1600–2400 px по ширине |
| `assets/images/shoe-side.webp` | Дополнительный вид для будущего расширения | Прозрачный фон, до 2000 px |
| `assets/images/video-poster.webp` | Постер обоих видео и Open Graph | 1600×900 px, до 250 КБ |
| `assets/images/favicon.svg` | Иконка вкладки | В репозитории уже есть нейтральная заглушка |
| `assets/videos/origami-film.mp4` | Фон первого экрана | 6–12 секунд, без звука, цикличный монтаж |
| `assets/videos/running-film.mp4` | Основной видеоблок | 16:9, со звуком при необходимости |

Файлы нужно положить по указанным путям без изменения имён. Изображение не следует растягивать или заранее добавлять в него декоративный фон.

## Локальный запуск

Из корня проекта:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`. Можно также открыть `index.html` напрямую, но локальный сервер точнее воспроизводит поведение GitHub Pages и загрузку видео.

## Публикация на GitHub Pages

1. Откройте **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выберите **GitHub Actions**.
3. Отправьте изменения в ветку `main`.
4. Workflow `.github/workflows/pages.yml` опубликует сайт автоматически.

Все пути относительные, поэтому сайт работает из подпапки `/Mizuno-Origami-Pack/`.

## Оптимизация видео

Для фонового видео важнее быстрый старт, чем высокое разрешение. Рекомендуется 720p или 1080p, H.264, без аудиодорожки и размер до 4–6 МБ.

Пример с FFmpeg:

```bash
ffmpeg -i source.mp4 -an -vf "scale=1280:-2" -c:v libx264 -crf 25 -preset slow -movflags +faststart assets/videos/origami-film.mp4
```

Для основного ролика можно оставить звук и использовать `-crf 23`. Перед публикацией проверьте воспроизведение на iPhone: ролик должен быть закодирован в H.264/AAC и иметь `yuv420p`.

## Замена изображений и текстов

- Медиа заменяются простым копированием файлов в `assets/images` и `assets/videos`.
- Все тексты находятся в `index.html` внутри соответствующих `<section>`.
- Цвета, типографика и основные размеры заданы CSS-переменными в начале `styles.css`.
- При смене главного изображения обновите `alt` и `og:image` в `index.html`.
